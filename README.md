# Airmark

Airmark is a live-production coordination and broadcast engine built for
camera operators and production crews at live-streamed events — churches,
conferences, weddings, and school events — who currently coordinate with no
professional intercom or tally hardware.

**Tier 2 — Coordination Layer:** phone-only, real-time tally/monitor,
run-of-show sync, discreet crew signals, highlight marking, equipment status,
and scheduling. Zero extra hardware required.

**Tier 1 — Production Engine:** a remote-control layer over free OBS Studio
(via obs-websocket), giving volunteer teams broadcast-level multi-camera
output — scene switching, overlays, reliability failsafes, and audio control
— without professional broadcast budgets.

Built by [TGO DevStudio](https://github.com/testimonygboroye).

## Stack
React + Vite + TypeScript · Tailwind CSS · Node.js + Express + TypeScript ·
Socket.IO · MongoDB Atlas · JWT auth · Render (hosting) · PWA
